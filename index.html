# Purpose

The purpose of SMS Adda is to understand how vulnerable and how easy to detect faults and weak points are inside automated SMS systems. During this research we identified several weak points across different platforms — and we document them here.

  • 01 vulnerability // how systems break queue · rate limit · validation
  • 02 detection // how easy to spot visible · observable · reproducible
  • 03 disclosure // what we publish patterns · not exploits

// goal: defensive literacy, not a weaponised tool
