01 / Why we built this

Existing SMS tools in Nepal are either locked behind corporate contracts, charge per message with minimum commitments, or are so generic that delivering a simple OTP turns into a week-long integration project.

We wanted something a single developer could use in an afternoon. SMS Adda is the result — a clean interface, a straightforward API, and a set of Nepali SMS gateways wired together so one call gets through even if a single provider is down.

philosophy

03 / How it works

Four steps from the moment you press send to the message landing on the recipient's phone.

  1. 01

    You enter a number

    Any valid +977 mobile — 98 or 97 prefix, ten digits. Add as many numbers as you like in bulk mode.

  2. 02

    We validate and pick a gateway

    The phone number is checked, then our worker picks a gateway from six providers. In auto mode we rotate until one accepts; in manual mode you choose.

  3. 03

    The SMS is dispatched

    The chosen gateway sends the message. If it fails, we try the next one. You see every step in the live terminal trace.

  4. 04

    Delivered to the phone

    The recipient gets the message within seconds. Every send is confirmed in the response and logged in your session.

05 / Frequently asked

Is SMS Adda free to use?

There's no subscription. You only pay for the messages you send, and there's no minimum commitment. Bulk sends get progressively cheaper per message.

Which numbers can I send to?

Any Nepali mobile number — 10 digits starting with 98 or 97. Landlines and international numbers are not supported at this time.

What happens if a gateway fails?

We automatically rotate to the next available gateway. You'll see each attempt in the live terminal trace, and the winning gateway is highlighted at the end.

Do you store the phone numbers I send to?

No. Phone numbers are passed through to the gateway in memory and never written to disk or logged for more than the duration of your session. See the privacy policy for details.

Can I use this for my own product?

Yes. The API is a single POST endpoint that accepts a phone number and returns a success flag. Any language that can make an HTTP request works — no SDK required.

Is there a rate limit?

Yes — to protect the gateways and prevent abuse, we cap requests per phone number per hour. If you need higher throughput for a legitimate use case, reach out.

Who built this?

SMS Adda was designed and developed by Laxman Poudel. You can find more of his work at laxman-poudel.com.np.
